# Project libraries

LoopIO.kicad_sym contains selected symbols from the installed KiCad standard library and datasheet-derived DAC80501, TMUX1511 and LT3092 symbols. LoopIO.pretty contains copies of the corresponding standard KiCad footprint geometries. Standard-library material retains the upstream KiCad library licensing, including its schematic/PCB design exception; see https://www.kicad.org/libraries/license/.

The project sym-lib-table and fp-lib-table use relative KIPRJMOD paths. No global libraries were changed. Footprint 3D model references remain upstream references and may require the usual KiCad model path configuration.
